# abitaprima-assets

Texture PBR per [AbitaPrima](https://github.com/acomelli91/abitaprima), servite da jsDelivr:
`https://cdn.jsdelivr.net/gh/nfranchetti-svg/abitaprima-assets@main/textures/<id>/<mappa>.jpg`

Tutte le texture vengono da [Poly Haven](https://polyhaven.com) e sono CC0 (pubblico dominio): nessuna attribuzione dovuta, la citiamo per riconoscenza. Mappe a 1K in JPG: `diffuse`, `normal` (OpenGL), `rough`, `ao`. `manifest.json` riporta nome, dimensione reale in metri e mappe disponibili di ogni set.
